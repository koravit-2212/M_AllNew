# Feature: จัดการข้อมูลผู้ใช้บริการ (Manage User Data)
Spec ID: SPEC-LIB-010 | Source: Use Case Specification (UC-10) | Use case: UC-10
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
เจ้าหน้าที่ห้องสมุดที่มีสิทธิ์สามารถตรวจสอบ เพิ่ม และแก้ไขข้อมูลผู้ใช้บริการได้อย่างปลอดภัย
โดยทุกการแก้ไขต้องถูกบันทึกเป็นประวัติเพื่อการตรวจสอบย้อนหลัง

## Scope
### In scope
- ตรวจสอบสิทธิ์เจ้าหน้าที่ก่อนเข้าถึงเมนูจัดการข้อมูล
- ค้นหา แสดง เพิ่ม/แก้ไขข้อมูลผู้ใช้บริการ และบันทึกการเปลี่ยนแปลง
### Out of scope
- การตรวจสอบสิทธิ์เข้าใช้บริการของนักศึกษาแบบ real-time -> UC-02 ตรวจสอบสิทธิ์การเข้าใช้บริการ
- การจัดการข้อมูลหนังสือ/บริการ -> UC-11 จัดการข้อมูลหนังสือและบริการ
- การจัดการข้อมูลระบบอื่น ๆ (ตั้งค่าทั่วไป) -> UC-13 จัดการข้อมูลระบบ

## Constraints
- ROLE-STAFF-02 เฉพาะเจ้าหน้าที่ที่มีสิทธิ์เท่านั้นที่สามารถแก้ไขข้อมูลผู้ใช้ได้
- DOM-PDPA-01 การเข้าถึง/แก้ไขข้อมูลส่วนบุคคลของผู้ใช้บริการต้องบันทึก audit log ทุกครั้ง

## Requirements
- FR-USR-01 ระบบต้องตรวจสอบสิทธิ์เจ้าหน้าที่ก่อนอนุญาตให้เข้าถึงเมนูจัดการข้อมูลผู้ใช้บริการ
  <- UC-10 ขั้นที่ 1-2
- FR-USR-02 ระบบต้องให้เจ้าหน้าที่ค้นหาข้อมูลผู้ใช้และแสดงข้อมูลที่พบ                      <- UC-10 ขั้นที่ 3-4
- FR-USR-03 ระบบต้องให้เจ้าหน้าที่เพิ่ม/แก้ไขข้อมูลผู้ใช้ และบันทึกข้อมูลลงฐานข้อมูล           <- UC-10 ขั้นที่ 5-6
- FR-USR-04 เมื่อเจ้าหน้าที่ไม่มีสิทธิ์จัดการข้อมูล ระบบต้องปฏิเสธการเข้าถึงและแจ้งเตือน       <- UC-10 exception 2a

## Quality Requirements
- NFR-SEC-04 เฉพาะเจ้าหน้าที่ที่มีสิทธิ์เท่านั้นที่สามารถแก้ไขข้อมูลผู้ใช้ได้
- NFR-AUDIT-01 ระบบต้องบันทึก log การแก้ไขข้อมูลผู้ใช้ทุกครั้ง

## Acceptance Criteria
- [ ] AC-USR-01 (FR-USR-03, NFR-AUDIT-01)
      Given เจ้าหน้าที่มีสิทธิ์จัดการข้อมูล
      When  เจ้าหน้าที่แก้ไขข้อมูลผู้ใช้บริการ
      Then  ระบบต้องบันทึกข้อมูลที่แก้ไขและปรับปรุงฐานข้อมูล พร้อมบันทึก log
- [ ] AC-USR-02 (FR-USR-04)
      Given เจ้าหน้าที่ไม่มีสิทธิ์จัดการข้อมูล
      When  เจ้าหน้าที่พยายามแก้ไขข้อมูล
      Then  ระบบต้องปฏิเสธการเข้าถึงและแจ้งเตือน

## Assumptions & Open Questions
- ASM-01 สิทธิ์การจัดการข้อมูลผู้ใช้บริการถูกกำหนดเป็นระดับ role ของเจ้าหน้าที่ในระบบ
- Q-01 ต้องเก็บ audit log การแก้ไขข้อมูลผู้ใช้ไว้นานเท่าใด (สอดคล้องกับ PDPA หรือไม่)?
