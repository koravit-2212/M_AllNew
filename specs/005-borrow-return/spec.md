# Feature: ยืม-คืนหนังสือ (Book Loan / Return)
Spec ID: SPEC-LNS-001 | Source: Use Case Specification ระบบห้องสมุด, UC-05 | Use case: UC-05
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
ผู้มีสิทธิ์ยืมหนังสือสแกนบัตรและหนังสือที่เครื่องอัตโนมัติหรือเคาน์เตอร์เพื่อยืม และนำหนังสือมาสแกนคืน
โดยระบบตรวจสอบสิทธิ์การยืม บันทึกรายการ แจ้งกำหนดคืน และแจ้งเตือนล่วงหน้า เพื่อให้ห้องสมุดควบคุม
และติดตามสถานะหนังสือได้ถูกต้อง

## Scope
### In scope
- ยืม: ตรวจสอบสิทธิ์การยืม บันทึกการยืม แจ้งวันกำหนดคืน ตั้งการแจ้งเตือนล่วงหน้า
- คืน: ตรวจสอบรายการยืม บันทึกการคืน แจ้งผล และแจ้งกรณีเกินกำหนด
- ให้ผู้ใช้บริการตรวจสอบประวัติการยืม-คืนของตนเอง
### Out of scope
- การค้นหาหนังสือ (UC-03)
- การเพิ่ม/แก้ไขข้อมูลหนังสือ (UC-11)
- การคำนวณ/เรียกเก็บค่าปรับ (ยังไม่ได้ระบุใน SRS - ดู Open Question)

## Constraints
- CON-LNS-01 การยืมหนังสือต้องเป็นไปตามระเบียบและสิทธิ์การยืมของห้องสมุด (BR-LNS-01)
- CON-LNS-02 ผู้ใช้บริการต้องคืนหนังสือภายในระยะเวลาที่ห้องสมุดกำหนด (BR-LNS-02)

## Requirements
- FR-LNS-01 ระบบต้องให้บริการยืมหนังสือผ่านเครื่องยืมอัตโนมัติหรือเคาน์เตอร์ โดยสแกนบัตรและบาร์โค้ด/QR Code ของหนังสือ  <- UC-05 ยืม ขั้น 1-3
- FR-LNS-02 ระบบต้องตรวจสอบสิทธิ์การยืมก่อนบันทึกรายการยืม                                              <- UC-05 ยืม ขั้น 4
- FR-LNS-03 เมื่อยืมสำเร็จ ระบบต้องบันทึกข้อมูลการยืม แสดงวันกำหนดคืน และตั้งการแจ้งเตือนล่วงหน้า          <- UC-05 ยืม ขั้น 5-6
- FR-LNS-04 ระบบต้องปฏิเสธการยืมเมื่อเกินจำนวนหนังสือที่สามารถยืมได้ หรือหนังสือถูกยืมอยู่แล้ว                <- UC-05 exception 4a, 4b
- FR-LNS-05 ระบบต้องตรวจสอบรายการยืมและบันทึกการคืนเมื่อสแกนหนังสือคืน                                <- UC-05 คืน ขั้น 1-4
- FR-LNS-06 เมื่อคืนหนังสือเกินกำหนด ระบบต้องแจ้งข้อมูลการเกินกำหนดพร้อมผลการคืน                        <- UC-05 คืน ขั้น 5, exception 5a
- FR-LNS-07 ระบบต้องให้ผู้ใช้บริการตรวจสอบประวัติการยืม-คืนหนังสือของตนเองได้

## Quality Requirements
- NFR-PRF-01 ระบบต้องรองรับผู้ใช้งานพร้อมกันได้อย่างน้อย 500 คน
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-REL-01 ระบบต้องมีการสำรองข้อมูลอย่างสม่ำเสมอ

## Acceptance Criteria
- [ ] AC-LNS-01 (FR-LNS-02, FR-LNS-03)
      Given นักศึกษามีสิทธิ์ยืมและหนังสือที่ต้องการว่างอยู่
      When  นักศึกษาสแกนบัตรและสแกนหนังสือ
      Then  ระบบบันทึกการยืมและแสดงวันกำหนดคืน
- [ ] AC-LNS-02 (FR-LNS-04)
      Given นักศึกษามีจำนวนหนังสือที่ยืมครบตามสิทธิ์แล้ว
      When  นักศึกษาพยายามยืมหนังสือเพิ่ม
      Then  ระบบไม่อนุญาตให้ยืมและแจ้งเหตุผล
- [ ] AC-LNS-03 (FR-LNS-05, FR-LNS-06)
      Given นักศึกษานำหนังสือที่เกินกำหนดคืนมาคืน
      When  นักศึกษาสแกนหนังสือคืน
      Then  ระบบบันทึกการคืนและแจ้งข้อมูลการเกินกำหนด
- [ ] AC-LNS-04 (FR-LNS-07)
      Given นักศึกษาเคยมีประวัติการยืม-คืนหนังสือ
      When  นักศึกษาเปิดดูประวัติการยืม-คืน
      Then  ระบบแสดงประวัติการยืม-คืนที่ถูกต้องครบถ้วน
