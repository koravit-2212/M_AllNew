# Feature: ยืม-คืนหนังสือ (Borrow/Return Book)
Spec ID: SPEC-LIB-005 | Source: Use Case Specification (UC-05) | Use case: UC-05
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
ผู้ใช้บริการที่มีสิทธิ์ยืมหนังสือสามารถยืมหรือคืนหนังสือผ่านเครื่องอัตโนมัติหรือเคาน์เตอร์ได้อย่างถูกต้อง
รวดเร็ว และตรวจสอบย้อนหลังได้

## Scope
### In scope
- ยืมหนังสือ: ตรวจสอบสิทธิ์การยืม บันทึกรายการยืม และแจ้งวันกำหนดคืน
- คืนหนังสือ: ตรวจสอบรายการยืม บันทึกการคืน และแสดงผลการคืน
### Out of scope
- การค้นหาหนังสือ -> UC-03 ค้นหาหนังสือ
- การยืนยันตัวตน/ตรวจสอบสิทธิ์เข้าใช้บริการห้องสมุด -> UC-01, UC-02 (ถือเป็น precondition)
- การจัดการข้อมูลหนังสือ (เพิ่ม/แก้ไข/ลบ) -> UC-11 จัดการข้อมูลหนังสือและบริการ

## Constraints
- CON-DEVICE-01 รองรับการทำรายการผ่านเครื่องอัตโนมัติหรือเคาน์เตอร์เจ้าหน้าที่
- DOM-DATA-01 ข้อมูลการยืม-คืนต้องถูกต้องและตรวจสอบย้อนหลังได้

## Requirements
- FR-BRW-01 ระบบต้องตรวจสอบสิทธิ์การยืมของนักศึกษาเมื่อสแกนบัตรและสแกนบาร์โค้ด/QR Code
  ของหนังสือ                                                          <- UC-05 (ยืม) ขั้นที่ 1-4
- FR-BRW-02 เมื่อมีสิทธิ์ยืม ระบบต้องบันทึกข้อมูลการยืมและแสดงวันกำหนดคืน                <- UC-05 (ยืม) ขั้นที่ 5-7
- FR-BRW-03 เมื่อนักศึกษายืมหนังสือครบตามจำนวนสิทธิ์แล้ว ระบบต้องไม่อนุญาตให้ยืมเพิ่ม
  <- UC-05 exception 4a
- FR-BRW-04 เมื่อหนังสือที่ต้องการถูกยืมอยู่ ระบบต้องแจ้งสถานะให้ทราบ                    <- UC-05 exception 4b
- FR-BRW-05 ระบบต้องตรวจสอบรายการยืมและบันทึกการคืนเมื่อนักศึกษาสแกนหนังสือคืน           <- UC-05 (คืน) ขั้นที่ 1-5
- FR-BRW-06 เมื่อคืนหนังสือเกินกำหนด ระบบต้องแจ้งข้อมูลการเกินกำหนด                     <- UC-05 exception 5a

## Quality Requirements
- NFR-PERF-05 ระบบต้องบันทึกรายการยืม/คืนภายใน 3 วินาที
- NFR-DATA-01 ข้อมูลการยืม-คืนต้องถูกต้องและตรวจสอบย้อนหลังได้

## Acceptance Criteria
- [ ] AC-BRW-01 (FR-BRW-02, NFR-PERF-05)
      Given นักศึกษามีสิทธิ์ยืมและหนังสือที่ต้องการว่างอยู่
      When  นักศึกษาสแกนบัตรและสแกนหนังสือ
      Then  ระบบต้องบันทึกการยืมและแสดงวันกำหนดคืน
- [ ] AC-BRW-02 (FR-BRW-03)
      Given นักศึกษามีจำนวนหนังสือที่ยืมครบตามสิทธิ์แล้ว
      When  นักศึกษาพยายามยืมหนังสือเพิ่ม
      Then  ระบบต้องไม่อนุญาตให้ยืมและแจ้งเหตุผล
- [ ] AC-BRW-03 (FR-BRW-04)
      Given หนังสือที่ต้องการถูกยืมอยู่โดยผู้อื่น
      When  นักศึกษาพยายามยืมหนังสือนั้น
      Then  ระบบต้องแจ้งสถานะว่าหนังสือถูกยืมอยู่
- [ ] AC-BRW-04 (FR-BRW-06)
      Given นักศึกษานำหนังสือมาคืนหลังวันกำหนดคืน
      When  ระบบบันทึกการคืน
      Then  ระบบต้องแจ้งข้อมูลการเกินกำหนด

## Assumptions & Open Questions
- ASM-01 จำนวนสิทธิ์การยืมสูงสุดต่อคนถูกกำหนดไว้ล่วงหน้าในระบบ (ไม่ได้ระบุค่าตัวเลขในเอกสารต้นทาง)
- Q-01 การเกินกำหนดคืนมีค่าปรับหรือบทลงโทษหรือไม่ และเชื่อมโยงกับสิทธิ์การยืมครั้งถัดไปอย่างไร?
