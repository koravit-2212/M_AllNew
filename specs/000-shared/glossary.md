# คำศัพท์ที่ใช้ร่วมกัน (glossary)
Status: v1 | Updated: 2569-10-07

ทุก spec ต้องใช้คำเดียวกันสำหรับสิ่งเดียวกัน ถ้าเจอคำใหม่ให้เพิ่มที่นี่ก่อน

- ผู้รับบริการ = คนที่มาตรวจสุขภาพ (ไม่ใช้คำว่า "ผู้ป่วย" หรือ "ลูกค้า")
- HN = Hospital Number รหัสผู้รับบริการที่ HIS ออกให้ ใช้แทนเลขบัตรประชาชนในทุกตาราง
- ช่วงเวลา (slot) = ช่วงเวลาตรวจที่มีโควตาที่นั่งของตัวเอง เช่น 09.00 น.
- ที่นั่งคงเหลือ = โควตาของช่วงเวลา ลบด้วยจำนวนการจองที่ยังไม่ถูกยกเลิก
- คิวที่ยังไม่ได้ใช้ = การจองที่สถานะยังเป็น "จองแล้ว"
- วันเดียวกัน = เทียบด้วยเขตเวลา Asia/Bangkok
