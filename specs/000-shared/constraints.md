# Constraint ที่ใช้ร่วมทุกฟีเจอร์ (shared constraints)
Status: v1 | Updated: 2569-10-07 | Source: SRS v0.3 ข้อ 2.4, 3.3, 3.4

กติกา: Constraint ที่ใช้มากกว่า 1 ฟีเจอร์ เขียนที่นี่ **ที่เดียว** spec ของแต่ละฟีเจอร์อ้าง ID ในหมวด Constraints ไม่ copy ข้อความ
ถ้าแก้ไฟล์นี้ ต้องทำ CR และดู Impact Analysis กับทุก spec ที่อ้าง ID นั้น (ดู rtm.md ของแต่ละฟีเจอร์)

## เทคโนโลยี (CON)
- CON-TECH-01 ใช้ฐานข้อมูล PostgreSQL ตามมาตรฐานฝ่าย IT ของโรงพยาบาล
  (2569-09-22 เปลี่ยนจาก MySQL)

## กฎของโดเมนและกฎหมาย (DOM)
- DOM-PDPA-01 บันทึก audit log ทุกครั้งที่เข้าถึงข้อมูลสุขภาพ (ผู้เข้าถึง, เวลา, รหัสผู้รับบริการ)
  เก็บไม่น้อยกว่า 1 ปี

## การเชื่อมต่อระบบภายนอก (IF)
- IF-IDP-01 ต้องได้รับผลยืนยันตัวตนจากระบบยืนยันตัวตนก่อนเข้าถึงข้อมูลผู้รับบริการ
- IF-HIS-01 ค้นข้อมูลผู้รับบริการจาก HIS ด้วยเลขบัตรประชาชน แล้วอ้างอิงภายในระบบด้วย HN
  ไม่เก็บเลขบัตรประชาชนในตารางใด ๆ ของระบบ
- IF-NOT-01 ส่งข้อความผ่านระบบแจ้งเตือน SMS/LINE แบบ asynchronous
  (งานที่สั่งส่งข้อความต้องไม่รอผลการส่ง)
