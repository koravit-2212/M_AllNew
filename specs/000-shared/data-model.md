# ข้อมูลที่หลายฟีเจอร์ใช้ร่วมกัน (shared data model)
Status: v1 | Updated: 2569-10-07

เขียนเฉพาะสิ่งที่มากกว่า 1 ฟีเจอร์ใช้ ฟิลด์ที่ใช้เฉพาะฟีเจอร์เดียว ไปอยู่ใน plan.md ของฟีเจอร์นั้น

- DM-01 Patient (ผู้รับบริการ): อ้างด้วย HN เท่านั้น ไม่มีเลขบัตรประชาชน (IF-HIS-01)
- DM-02 Package (แพ็กเกจตรวจสุขภาพ): รหัสแพ็กเกจ ชื่อ
- DM-03 Slot (ช่วงเวลา): วัน เวลาเริ่ม แพ็กเกจ โควตา ที่นั่งคงเหลือ (โควตากำหนดโดย UC-09)
- DM-04 Booking (การจอง): HN, Slot, สถานะ (จองแล้ว / ใช้แล้ว), หมายเลขคิว (รูปแบบรอ Q-02 ของ 001-booking)
- DM-05 AuditLog: ผู้เข้าถึง เวลา HN การกระทำ (DOM-PDPA-01)
