# Feature: ตรวจสอบเวลาเปิดให้บริการ (Operating Hours)
Spec ID: SPEC-SCH-001 | Source: Use Case Specification ระบบห้องสมุด, UC-09 | Use case: UC-09
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
นักศึกษาเปิดดูวันและเวลาเปิด-ปิดของห้องสมุดเพื่อวางแผนการเข้าใช้บริการล่วงหน้า โดยข้อมูลต้องตรงตาม
ประกาศของมหาวิทยาลัยเสมอ

## Scope
### In scope
- แสดงวันและเวลาเปิด-ปิดให้บริการของห้องสมุด ตามตารางเวลาที่มีในระบบ
### Out of scope
- การแก้ไข/กำหนดตารางเวลาเปิด-ปิด (ส่วนนี้ควรอยู่ใน UC-13 จัดการข้อมูลระบบ)

## Constraints
- CON-SCH-01 เวลาเปิด-ปิดและวันหยุดของห้องสมุดต้องเป็นไปตามประกาศของมหาวิทยาลัย (BR-SCH-01)

## Requirements
- FR-SCH-01 ระบบต้องแสดงวันและเวลาเปิด-ปิดให้บริการของห้องสมุดเมื่อนักศึกษาเลือกเมนูนี้    <- UC-09 ขั้น 1-4

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-REL-02 ระบบต้องสามารถให้บริการได้อย่างต่อเนื่องในช่วงเวลาที่ห้องสมุดเปิดให้บริการ

## Acceptance Criteria
- [ ] AC-SCH-01 (FR-SCH-01)
      Given มีข้อมูลตารางเวลาให้บริการในระบบ
      When  นักศึกษาเลือกเมนูเวลาเปิดให้บริการ
      Then  ระบบแสดงวันและเวลาเปิด-ปิดที่ถูกต้อง

## Assumptions & Open Questions
- ASM-01 ตารางเวลาเปิด-ปิดถูกป้อนเข้าระบบโดยเจ้าหน้าที่ผ่าน UC-13 และมีผลทันทีที่บันทึก
- Q-01 กรณีวันหยุดพิเศษ/เปลี่ยนแปลงเวลาชั่วคราว ระบบต้องแสดงแยกจากตารางเวลาปกติหรือไม่? -> ถามห้องสมุด
