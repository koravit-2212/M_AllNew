# Feature: จัดการข้อมูลหนังสือ/บริการ (Manage Book & Service Data)
Spec ID: SPEC-LIB-011 | Source: Use Case Specification (UC-11) | Use case: UC-11
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
บรรณารักษ์และเจ้าหน้าที่ห้องสมุดสามารถเพิ่ม แก้ไข หรือลบข้อมูลหนังสือและบริการต่าง ๆ ได้
โดยระบบตรวจสอบความถูกต้องของข้อมูลก่อนบันทึกทุกครั้ง เพื่อให้ข้อมูลในระบบเป็นปัจจุบัน

## Scope
### In scope
- เลือกเมนูจัดการข้อมูล และเลือกข้อมูลหนังสือหรือบริการที่ต้องการจัดการ
- เพิ่ม แก้ไข หรือลบข้อมูล พร้อมตรวจสอบความถูกต้องก่อนบันทึก
### Out of scope
- การค้นหาหนังสือฝั่งนักศึกษา -> UC-03 ค้นหาหนังสือ
- การจัดการข้อมูลผู้ใช้บริการ -> UC-10 จัดการข้อมูลผู้ใช้บริการ
- การจัดการข้อมูลระบบทั่วไป (ตั้งค่าระบบ) -> UC-13 จัดการข้อมูลระบบ

## Constraints
- ROLE-STAFF-03 ผู้มีสิทธิ์จัดการข้อมูลคือบรรณารักษ์และเจ้าหน้าที่ห้องสมุด
- DOM-DATA-03 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึกทุกครั้ง

## Requirements
- FR-BKS-01 ระบบต้องแสดงเมนูจัดการข้อมูล และให้เจ้าหน้าที่เลือกข้อมูลหนังสือหรือบริการ       <- UC-11 ขั้นที่ 1-3
- FR-BKS-02 ระบบต้องให้เจ้าหน้าที่เพิ่ม แก้ไข หรือลบข้อมูลหนังสือ/บริการ                    <- UC-11 ขั้นที่ 4
- FR-BKS-03 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึก และบันทึกข้อมูลเมื่อถูกต้อง       <- UC-11 ขั้นที่ 5-6
- FR-BKS-04 เมื่อข้อมูลที่กรอกไม่ถูกต้องตามรูปแบบ ระบบต้องแจ้งเตือนและไม่บันทึกข้อมูล        <- UC-11 exception 5a

## Quality Requirements
- NFR-DATA-03 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึกทุกครั้ง
- NFR-PERF-09 ระบบต้องบันทึกการเปลี่ยนแปลงข้อมูลภายใน 3 วินาที

## Acceptance Criteria
- [ ] AC-BKS-01 (FR-BKS-03, NFR-PERF-09)
      Given เจ้าหน้าที่กรอกข้อมูลหนังสือ/บริการถูกต้องครบถ้วน
      When  เจ้าหน้าที่ยืนยันการบันทึก
      Then  ระบบต้องบันทึกข้อมูลและปรับปรุงให้เป็นปัจจุบันภายใน 3 วินาที
- [ ] AC-BKS-02 (FR-BKS-04)
      Given ข้อมูลที่กรอกไม่ถูกต้องตามรูปแบบ
      When  เจ้าหน้าที่ยืนยันการบันทึก
      Then  ระบบต้องแจ้งเตือนและไม่บันทึกข้อมูล

## Assumptions & Open Questions
- ASM-01 สิทธิ์การจัดการข้อมูลหนังสือ/บริการจำกัดเฉพาะบรรณารักษ์และเจ้าหน้าที่ห้องสมุด
- Q-01 การลบข้อมูลหนังสือที่มีประวัติการยืมอยู่ควรทำแบบ soft delete หรือไม่ เพื่อรักษาความสอดคล้อง
  กับ UC-05 (ยืม-คืนหนังสือ)?
