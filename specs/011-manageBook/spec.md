# Feature: จัดการข้อมูลหนังสือ/บริการ (Catalog Management)
Spec ID: SPEC-CAT-001 | Source: Use Case Specification ระบบห้องสมุด, UC-11 | Use case: UC-11
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
บรรณารักษ์/เจ้าหน้าที่เพิ่ม แก้ไข หรือลบข้อมูลหนังสือและบริการต่าง ๆ โดยระบบตรวจสอบความถูกต้อง
ของข้อมูลก่อนบันทึก เพื่อให้ข้อมูลหนังสือและบริการที่นักศึกษาเห็นเป็นปัจจุบันเสมอ

## Scope
### In scope
- เลือกเมนูจัดการข้อมูล และเลือกรายการหนังสือ/บริการที่ต้องการจัดการ
- เพิ่ม/แก้ไข/ลบข้อมูลหนังสือหรือบริการ พร้อมตรวจสอบรูปแบบข้อมูลก่อนบันทึก และบันทึก Audit Log
### Out of scope
- การค้นหาหนังสือฝั่งนักศึกษา (UC-03)
- การจัดการข้อมูลผู้ใช้บริการ (UC-10) และข้อมูลระบบอื่น (UC-13)

## Constraints
- CON-AUDIT-01 ทุกการกระทำที่สำคัญของเจ้าหน้าที่ต้องถูกบันทึกลง Audit Log (NFR-SEC-02)
- CON-SEC-01 ทุกการเชื่อมต่อต้องใช้ HTTPS (NFR-SEC-03)

## Requirements
- FR-CAT-01 ระบบต้องให้เจ้าหน้าที่เลือกเมนูจัดการข้อมูล และเลือกข้อมูลหนังสือหรือบริการที่ต้องการจัดการ  <- UC-11 ขั้น 1-3
- FR-CAT-02 ระบบต้องให้เจ้าหน้าที่เพิ่ม แก้ไข หรือลบข้อมูลหนังสือ/บริการ                              <- UC-11 ขั้น 4
- FR-CAT-03 ระบบต้องตรวจสอบความถูกต้องของรูปแบบข้อมูลก่อนบันทึก และบันทึกพร้อม Audit Log เมื่อผ่าน  <- UC-11 ขั้น 5-6
- FR-CAT-04 เมื่อข้อมูลที่กรอกไม่ถูกต้องตามรูปแบบ ระบบต้องแจ้งเตือนและไม่บันทึกข้อมูล                <- UC-11 exception 5a

## Quality Requirements
- NFR-SEC-02 ระบบต้องมีการบันทึก Audit Log สำหรับการกระทำที่สำคัญของ Admin/เจ้าหน้าที่
- NFR-SEC-03 ระบบต้องใช้การเชื่อมต่อที่ปลอดภัย เช่น HTTPS

## Acceptance Criteria
- [ ] AC-CAT-01 (FR-CAT-01)
      Given มีข้อมูลหนังสือ/บริการอยู่ในระบบ
      When  เจ้าหน้าที่เลือกเมนูจัดการข้อมูลและเลือกรายการที่ต้องการ
      Then  ระบบแสดงข้อมูลปัจจุบันของรายการนั้นให้เพิ่ม/แก้ไข/ลบ
- [ ] AC-CAT-02 (FR-CAT-02, FR-CAT-03)
      Given เจ้าหน้าที่กรอกข้อมูลหนังสือ/บริการถูกต้องครบถ้วน
      When  เจ้าหน้าที่ยืนยันการบันทึก
      Then  ระบบบันทึกข้อมูลและปรับปรุงให้เป็นปัจจุบัน พร้อมมี Audit Log
- [ ] AC-CAT-03 (FR-CAT-02, FR-CAT-04)
      Given ข้อมูลที่กรอกไม่ถูกต้องตามรูปแบบ
      When  เจ้าหน้าที่ยืนยันการบันทึก
      Then  ระบบแจ้งเตือนและไม่บันทึกข้อมูล

## Assumptions & Open Questions
- ASM-01 สิทธิ์การเพิ่ม/แก้ไข/ลบข้อมูลหนังสือจำกัดเฉพาะบรรณารักษ์และเจ้าหน้าที่ห้องสมุดที่ได้รับมอบหมาย
- Q-01 การลบข้อมูลหนังสือเป็นการลบถาวรหรือ soft delete (เพื่อรักษาประวัติการยืม-คืนที่อ้างอิงหนังสือเล่มนั้น)? -> ถามฝ่าย IT/บรรณารักษ์
- Q-02 "รูปแบบข้อมูลไม่ถูกต้อง" ครอบคลุมเงื่อนไขใดบ้าง (ฟิลด์บังคับ/รูปแบบ ISBN ฯลฯ)? -> ถามบรรณารักษ์
