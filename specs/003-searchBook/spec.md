# Feature: ค้นหาหนังสือ (Book Search)
Spec ID: SPEC-SRC-001 | Source: Use Case Specification ระบบห้องสมุด, UC-03 | Use case: UC-03
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
นักศึกษาค้นหาหนังสือด้วยชื่อ ผู้แต่ง หรือคำค้น แล้วเห็นรายการหนังสือพร้อมสถานะ (ว่าง/ถูกยืม)
เพื่อให้ตัดสินใจไปยืมหรือจองต่อได้อย่างรวดเร็ว

## Scope
### In scope
- รับคำค้น (ชื่อหนังสือ/ผู้แต่ง/คำค้นทั่วไป) และค้นหาจากฐานข้อมูลหนังสือ
- แสดงรายการผลลัพธ์พร้อมสถานะความพร้อมใช้งานของแต่ละเล่ม และหน้ารายละเอียดหนังสือ
### Out of scope
- การยืม/คืนหนังสือจริง (UC-05)
- การเพิ่ม/แก้ไข/ลบข้อมูลหนังสือ (UC-11)

## Constraints
- IF-CAT-01 ต้องอ่านข้อมูลหนังสือและสถานะจากฐานข้อมูลกลางเดียวกับ UC-05 (ยืม-คืน) และ UC-11 (จัดการข้อมูลหนังสือ)
  เพื่อให้สถานะ "ว่าง/ถูกยืม" ถูกต้องตรงกันทุกฟีเจอร์

## Requirements
- FR-SRC-01 ระบบต้องรับคำค้น (ชื่อหนังสือ/ผู้แต่ง/คำค้น/ISBN) และค้นหาข้อมูลจากฐานข้อมูล โดยรองรับ fuzzy/partial match (case-insensitive) บนฟิลด์ title, author, keywords, ISBN  <- UC-03 ขั้น 1-3
- FR-SRC-02 ระบบต้องแสดงรายการหนังสือที่ตรงกับคำค้นพร้อมสถานะสรุป (aggregated per-title) ในหน้ารายการผลลัพธ์ และเมื่อผู้ใช้เข้าดูรายละเอียดของเล่มใดให้แสดงสถานะระดับสำเนาแต่ละเล่ม (per-copy) พร้อมตำแหน่งจัดเก็บ  <- UC-03 ขั้น 4
- FR-SRC-03 ระบบต้องแสดงรายละเอียดหนังสือเมื่อผู้ใช้เลือกดู (อย่างน้อยต้องมี ชื่อ ผู้แต่ง เลขเรียกหนังสือ/ISBN หมวดหมู่ สถานะยืม-คืน ตำแหน่งจัดเก็บ)                              <- UC-03 ขั้น 5
- FR-SRC-04 เมื่อไม่พบหนังสือที่ตรงกับคำค้น ระบบต้องแสดงข้อความ "ไม่พบข้อมูลหนังสือ"      <- UC-03 exception 4a
- FR-SRC-05 เมื่อฐานข้อมูลตอบช้า หรือให้ผลลัพธ์ไม่ครบถ้วน ระบบต้องแสดงผลลัพธ์ที่ดึงมาได้ทันทีพร้อมแจ้งเตือนผู้ใช้ว่าผลลัพธ์เป็นบางส่วน (partial results) แทนการปิดการให้บริการทั้งหมด  <- UC-03 exception 3a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-PRF-03 (เสนอเพิ่ม) การค้นหาต้องแสดงผลภายใน 2–3 วินาที ภายใต้สภาวะที่รองรับผู้ใช้งานพร้อมกันอย่างน้อย 500 คน (ค่าประเมินจากทีม)

## Acceptance Criteria
- [ ] AC-SRC-01 (FR-SRC-01, FR-SRC-02)
      Given นักศึกษาระบุคำค้นบนฟิลด์ที่รองรับ
      When  นักศึกษากดค้นหา
      Then  ระบบแสดงรายการหนังสือที่ตรงกับคำค้นภายในเวลาที่กำหนด โดยเรียงลำดับตามความเกี่ยวข้องและรองรับการแบ่งหน้า (pagination) 20–25 รายการต่อหน้า
- [ ] AC-SRC-02 (FR-SRC-04)
      Given ไม่มีหนังสือที่ตรงกับคำค้น
      When  นักศึกษากดค้นหา
      Then  ระบบแสดงข้อความ "ไม่พบข้อมูลหนังสือ"
- [ ] AC-SRC-03 (FR-SRC-05)
      Given ฐานข้อมูลหนังสือตอบช้าหรือให้ผลลัพธ์บางส่วน
      When  นักศึกษากดค้นหา
      Then  ระบบแสดงผลที่สามารถดึงได้ทันทีพร้อมข้อความแจ้งเตือนว่าเป็นผลลัพธ์บางส่วน (partial results); หากฐานข้อมูลไม่สามารถให้ผลใดๆ ได้ ให้ระบบแจ้งเตือนผู้ใช้ว่า "ฐานข้อมูลหนังสือไม่พร้อมใช้งาน"
- [ ] AC-SRC-04 (FR-SRC-03)
      Given นักศึกษาเห็นรายการหนังสือที่ตรงกับคำค้นแล้ว
      When  นักศึกษาเลือกดูรายละเอียดหนังสือเล่มใดเล่มหนึ่ง
      Then  ระบบแสดงรายละเอียดหนังสือเล่มนั้นอย่างครบถ้วน โดยมีอย่างน้อย: ชื่อ ผู้แต่ง เลขเรียกหนังสือ/ISBN หมวดหมู่ สถานะยืม-คืน และตำแหน่งจัดเก็บบนชั้น

## Assumptions & Open Questions
- ASM-01 สถานะ "ว่าง/ถูกยืม" อัปเดตแบบใกล้เคียง Real-time จากข้อมูลของ UC-05
- ASM-02 ทีมตกลงให้รองรับการค้นหาแบบ fuzzy/partial match (case-insensitive) เพื่ออำนวยความสะดวกในการค้นหา
- ASM-03 ทีมกำหนดขอบเขตการค้นหาที่ต้องรองรับเป็น `title`, `author`, `keywords` และ `ISBN/เลขเรียกหนังสือ` โดยใช้ partial match
- ASM-04 ผลการแสดงสถานะ: ในรายการค้นหาให้แสดงสถานะสรุปแบบ aggregated per-title และในหน้ารายละเอียดให้แสดงสถานะแบบ per-copy พร้อมตำแหน่งเล่ม
- ASM-05 เมื่อฐานข้อมูลตอบช้า/ให้ผลลัพธ์ไม่ครบ ให้ระบบแสดงผลที่มีพร้อมแจ้งเตือนผู้ใช้ (partial results) แทนการยกเลิกการให้บริการทั้งหมด
- ASM-06 ในหน้ารายละเอียดระบบต้องอย่างน้อยแสดง: ชื่อ ผู้แต่ง เลขเรียกหนังสือ/ISBN หมวดหมู่ สถานะยืม-คืน และตำแหน่งจัดเก็บบนชั้น
- ASM-07 ระบบต้องรองรับการแบ่งหน้า (pagination) 20–25 รายการต่อหน้า และเรียงลำดับผลลัพธ์ตามความเกี่ยวข้อง (relevance)
- ASM-08 ทีมกำหนดค่า NFR-PRF-03 ว่า Response Time ต้องไม่เกิน 2–3 วินาที และระบบต้องรองรับผู้ใช้งานพร้อมกันอย่างน้อย 500 คน
