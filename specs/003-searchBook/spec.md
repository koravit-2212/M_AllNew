# Feature: ค้นหาหนังสือ (Search Book)
Spec ID: SPEC-LIB-003 | Source: Use Case Specification (UC-03) | Use case: UC-03
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาค้นหาหนังสือที่ต้องการผ่านระบบห้องสมุดได้อย่างรวดเร็วและง่าย โดยค้นได้จากชื่อหนังสือ
ผู้แต่ง หรือคำค้นบางส่วน แล้วดูรายละเอียดหนังสือที่พบได้

## Scope
### In scope
- รับคำค้น (ชื่อหนังสือ/ผู้แต่ง/คำค้น) และค้นหาจากฐานข้อมูลห้องสมุด
- แสดงรายการหนังสือที่ตรงกับคำค้น และให้ดูรายละเอียดหนังสือ
### Out of scope
- การยืม-คืนหนังสือ -> UC-05 ยืม-คืนหนังสือ
- การจัดการ/เพิ่ม-แก้ไข-ลบข้อมูลหนังสือ -> UC-11 จัดการข้อมูลหนังสือและบริการ
- การยืนยันตัวตนก่อนใช้งาน -> UC-01 เข้าใช้บริการห้องสมุด (ถือเป็น precondition)

## Constraints
- IF-DB-01 ระบบต้องเชื่อมต่อฐานข้อมูลห้องสมุดเพื่อค้นหาข้อมูลหนังสือ

## Requirements
- FR-SRC-01 ระบบต้องรับคำค้น (ชื่อหนังสือ, ผู้แต่ง หรือคำค้น) จากนักศึกษา และค้นหาข้อมูล
  จากฐานข้อมูล                                                        <- UC-03 ขั้นที่ 1-3
- FR-SRC-02 ระบบต้องแสดงรายการหนังสือที่ตรงกับคำค้น และให้นักศึกษาเลือกดูรายละเอียดได้
  <- UC-03 ขั้นที่ 4-5
- FR-SRC-03 ระบบต้องรองรับการค้นหาแบบบางส่วนของชื่อหนังสือ/ชื่อผู้แต่ง
- FR-SRC-04 เมื่อไม่พบหนังสือที่ตรงกับคำค้น ระบบต้องแสดงข้อความ "ไม่พบข้อมูลหนังสือ"
  <- UC-03 alternative/exception 4a
- FR-SRC-05 เมื่อฐานข้อมูลไม่พร้อมใช้งาน ระบบต้องแจ้งเตือนผู้ใช้                <- UC-03 alternative/exception 3a

## Quality Requirements
- NFR-PERF-03 ระบบต้องแสดงผลการค้นหาภายใน 2 วินาที
- NFR-USAB-01 ระบบต้องรองรับการค้นหาแบบบางส่วนของชื่อหนังสือ/ชื่อผู้แต่ง

## Acceptance Criteria
- [ ] AC-SRC-01 (FR-SRC-01, FR-SRC-02, NFR-PERF-03)
      Given นักศึกษาระบุชื่อหนังสือที่มีอยู่ในฐานข้อมูล
      When  นักศึกษากดค้นหา
      Then  ระบบต้องแสดงรายการหนังสือที่ตรงกับคำค้นภายในเวลาที่กำหนด
- [ ] AC-SRC-02 (FR-SRC-04)
      Given ไม่มีหนังสือที่ตรงกับคำค้น
      When  นักศึกษากดค้นหา
      Then  ระบบต้องแสดงข้อความ "ไม่พบข้อมูลหนังสือ"
- [ ] AC-SRC-03 (FR-SRC-05)
      Given ระบบฐานข้อมูลไม่พร้อมใช้งาน
      When  นักศึกษากดค้นหา
      Then  ระบบต้องแจ้งเตือนผู้ใช้

## Assumptions & Open Questions
- ASM-01 การค้นหาไม่จำเป็นต้องยืนยันตัวตนก่อน (เข้าถึงได้แบบสาธารณะ) เว้นแต่จะระบุเป็นอย่างอื่น
- Q-01 ต้องรองรับการค้นหาแบบ filter เพิ่มเติม (หมวดหมู่, ปีพิมพ์) หรือไม่?
