# Feature: ค้นหาหนังสือ (Book Search)
Spec ID: SPEC-SRC-001 | Source: Use Case Specification ระบบห้องสมุด, UC-03 | Use case: UC-03
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
นักศึกษาค้นหาหนังสือด้วยชื่อ ผู้แต่ง หรือคำค้น แล้วเห็นรายการหนังสือพร้อมสถานะ (ว่าง/ถูกยืม)
เพื่อให้ตัดสินใจไปยืมหรือจองต่อได้อย่างรวดเร็ว

## Scope
### In scope
- รับคำค้น (ชื่อหนังสือ/ผู้แต่ง/คำค้นทั่วไป) และค้นหาจากฐานข้อมูลหนังสือ
- แสดงรายการผลลัพธ์พร้อมสถานะความพร้อมใช้งานของแต่ละเล่ม และหน้ารายละเอียดหนังสือ
### Out of scope
- การยืม/คืนหนังสือจริง (UC-05)
- การเพิ่ม/แก้ไข/ลบข้อมูลหนังสือ (UC-11)

## Constraints
- IF-CAT-01 ต้องอ่านข้อมูลหนังสือและสถานะจากฐานข้อมูลกลางเดียวกับ UC-05 (ยืม-คืน) และ UC-11 (จัดการข้อมูลหนังสือ)
  เพื่อให้สถานะ "ว่าง/ถูกยืม" ถูกต้องตรงกันทุกฟีเจอร์

## Requirements
- FR-SRC-01 ระบบต้องรับคำค้น (ชื่อหนังสือ/ผู้แต่ง/คำค้น) และค้นหาข้อมูลจากฐานข้อมูล        <- UC-03 ขั้น 1-3
- FR-SRC-02 ระบบต้องแสดงรายการหนังสือที่ตรงกับคำค้นพร้อมสถานะ (ว่าง/ถูกยืม)              <- UC-03 ขั้น 4
- FR-SRC-03 ระบบต้องแสดงรายละเอียดหนังสือเมื่อผู้ใช้เลือกดู                              <- UC-03 ขั้น 5
- FR-SRC-04 เมื่อไม่พบหนังสือที่ตรงกับคำค้น ระบบต้องแสดงข้อความ "ไม่พบข้อมูลหนังสือ"      <- UC-03 exception 4a
- FR-SRC-05 เมื่อฐานข้อมูลไม่พร้อมใช้งาน ระบบต้องแจ้งเตือนผู้ใช้และไม่แสดงผลลัพธ์ที่ไม่สมบูรณ์  <- UC-03 exception 3a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-PRF-03 (เสนอเพิ่ม) การค้นหาต้องแสดงผลภายในเวลาที่กำหนด (ดู Open Question Q-01)

## Acceptance Criteria
- [ ] AC-SRC-01 (FR-SRC-01, FR-SRC-02)
      Given นักศึกษาระบุชื่อหนังสือที่มีอยู่ในฐานข้อมูล
      When  นักศึกษากดค้นหา
      Then  ระบบแสดงรายการหนังสือที่ตรงกับคำค้นภายในเวลาที่กำหนด
- [ ] AC-SRC-02 (FR-SRC-04)
      Given ไม่มีหนังสือที่ตรงกับคำค้น
      When  นักศึกษากดค้นหา
      Then  ระบบแสดงข้อความ "ไม่พบข้อมูลหนังสือ"
- [ ] AC-SRC-03 (FR-SRC-05)
      Given ฐานข้อมูลหนังสือไม่พร้อมใช้งาน
      When  นักศึกษากดค้นหา
      Then  ระบบแจ้งเตือนผู้ใช้แทนการแสดงผลลัพธ์
- [ ] AC-SRC-04 (FR-SRC-03)
      Given นักศึกษาเห็นรายการหนังสือที่ตรงกับคำค้นแล้ว
      When  นักศึกษาเลือกดูรายละเอียดหนังสือเล่มใดเล่มหนึ่ง
      Then  ระบบแสดงรายละเอียดหนังสือเล่มนั้น (ชื่อ ผู้แต่ง สถานะ ตำแหน่งจัดเก็บ) ครบถ้วน

## Assumptions & Open Questions
- ASM-01 สถานะ "ว่าง/ถูกยืม" อัปเดตแบบใกล้เคียง Real-time จากข้อมูลของ UC-05
- Q-01 "เวลาที่กำหนด" ในเกณฑ์การยอมรับ (Acceptance Criteria เดิม) คือกี่วินาที และรองรับผู้ใช้พร้อมกันกี่คน? -> ถามห้องสมุด/ฝ่าย IT เพื่อกำหนดเป็น NFR-PRF-03 ที่วัดผลได้
- Q-02 ต้องรองรับการค้นหาแบบ fuzzy/สะกดผิดหรือไม่? -> ถามบรรณารักษ์
