# Feature: ตรวจสอบสิทธิ์การเข้าใช้บริการ (Check Service Privilege)
Spec ID: SPEC-LIB-002 | Source: Use Case Specification (UC-02) | Use case: UC-02
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
ระบบตรวจสอบว่านักศึกษามีสิทธิ์เข้าใช้บริการห้องสมุดหรือไม่ โดยอ้างอิงข้อมูลจากระบบบัตรนักศึกษา
ให้ผลลัพธ์ที่ถูกต้องและรวดเร็ว เพื่อส่งกลับไปให้ UC-01 ใช้ตัดสินใจอนุญาตการเข้าใช้บริการ

## Scope
### In scope
- รับข้อมูลนักศึกษาที่ส่งมาจาก UC-01 (เรียกใช้แบบ <<include>>)
- ส่งข้อมูลไปตรวจสอบกับระบบบัตรนักศึกษา และตรวจสอบสถานะของนักศึกษา
- แสดง/ส่งคืนผลการตรวจสอบสิทธิ์
### Out of scope
- การอ่าน QR Code/บัตร และการอนุญาตให้เข้าห้องสมุด -> UC-01 เข้าใช้บริการห้องสมุด
- การกำหนด/เพิกถอนสิทธิ์การเข้าใช้บริการของนักศึกษา -> UC-10 จัดการข้อมูลผู้ใช้บริการ

## Constraints
- IF-STD-01 ระบบต้องเชื่อมต่อกับระบบบัตรนักศึกษา (ระบบภายนอก) เพื่อตรวจสอบสถานะนักศึกษา
- REL-STD-01 เมื่อระบบบัตรนักศึกษาขัดข้องชั่วคราว ระบบต้องไม่ resend ซ้ำจนเกิดภาระงานกับระบบภายนอก
  (ให้แจ้งผู้ใช้แทน)

## Requirements
- FR-CHK-01 ระบบต้องรับข้อมูลนักศึกษาที่ได้จากขั้นตอนเข้าใช้บริการ (UC-01) และส่งไปตรวจสอบ
  กับระบบบัตรนักศึกษา                                                 <- UC-02 ขั้นที่ 1-2
- FR-CHK-02 ระบบต้องตรวจสอบสถานะของนักศึกษาจากข้อมูลที่ระบบบัตรนักศึกษาส่งกลับมา
  และแสดงผลการตรวจสอบ                                                 <- UC-02 ขั้นที่ 3-5
- FR-CHK-03 เมื่อไม่พบข้อมูลนักศึกษา ระบบต้องแสดงข้อความแจ้งเตือน                <- UC-02 exception 4a
- FR-CHK-04 เมื่อระบบบัตรนักศึกษาขัดข้อง ระบบต้องแจ้งให้ผู้ใช้ลองใหม่ภายหลัง       <- UC-02 exception 2a

## Quality Requirements
- NFR-PERF-02 ระบบต้องตรวจสอบสิทธิ์กับระบบบัตรนักศึกษาให้เสร็จภายใน 3 วินาที
- NFR-REL-01 ระบบต้องแจ้งเตือนผู้ใช้อย่างชัดเจนเมื่อระบบบัตรนักศึกษาขัดข้องชั่วคราว

## Acceptance Criteria
- [ ] AC-CHK-01 (FR-CHK-02, NFR-PERF-02)
      Given ระบบได้รับข้อมูลนักศึกษาที่ถูกต้อง
      When  ระบบส่งข้อมูลไปตรวจสอบกับระบบบัตรนักศึกษา
      Then  ระบบต้องแสดงผลสถานะสิทธิ์การเข้าใช้บริการที่ถูกต้องภายใน 3 วินาที
- [ ] AC-CHK-02 (FR-CHK-04, NFR-REL-01)
      Given ระบบบัตรนักศึกษาขัดข้อง
      When  ระบบพยายามตรวจสอบสิทธิ์นักศึกษา
      Then  ระบบต้องแจ้งให้ผู้ใช้ลองใหม่ภายหลัง
- [ ] AC-CHK-03 (FR-CHK-03)
      Given ไม่พบข้อมูลนักศึกษาในระบบบัตรนักศึกษา
      When  ระบบตรวจสอบสถานะ
      Then  ระบบต้องแสดงข้อความแจ้งเตือนว่าไม่พบข้อมูล

## Assumptions & Open Questions
- ASM-01 ระบบบัตรนักศึกษาเป็นระบบภายนอกที่มี interface แบบ synchronous สำหรับตรวจสอบสถานะ
- Q-01 เมื่อระบบบัตรนักศึกษาขัดข้อง ควร retry อัตโนมัติกี่ครั้งก่อนแจ้งผู้ใช้ให้ลองใหม่ภายหลัง?
