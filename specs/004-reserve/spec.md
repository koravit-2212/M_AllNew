# Feature: จอง/ใช้พื้นที่ในห้องสมุด (Space Booking)
Spec ID: SPEC-BKG-002 | Source: Use Case Specification ระบบห้องสมุด, UC-04 | Use case: UC-04
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
นักศึกษาที่มีสิทธิ์ใช้บริการเลือกพื้นที่และช่วงเวลาสำหรับอ่านหนังสือหรือทำงาน แล้วได้รับการยืนยันการจอง
ทันที เพื่อให้ห้องสมุดจัดสรรพื้นที่ได้เพียงพอและเป็นระเบียบ

## Scope
### In scope
- แสดงพื้นที่ที่ใช้งานได้ ให้เลือกพื้นที่และช่วงเวลา
- ตรวจสอบความว่างของพื้นที่ ณ เวลาที่เลือก บันทึกการจอง และแจ้งผล
### Out of scope
- การเข้าใช้บริการห้องสมุดจริง (UC-01)
- การยกเลิก/แก้ไขการจองพื้นที่ (ยังไม่ได้ระบุใน SRS - ดู Open Question)

## Constraints
- CON-ELG-01 ผู้จองต้องเป็นนักศึกษา บุคลากร หรือผู้ที่ได้รับอนุญาต (BR-ELG-01)
- CON-CONC-01 การตรวจสอบความว่างและบันทึกการจองต้องเป็น atomic operation เพื่อป้องกันการจองซ้อน
  เมื่อมีผู้ใช้หลายคนจองพื้นที่/ช่วงเวลาเดียวกันพร้อมกัน

## Requirements
- FR-BKG-01 ระบบต้องแสดงพื้นที่ที่สามารถใช้งานได้ให้นักศึกษาเลือก                                   <- UC-04 ขั้น 1-2
- FR-BKG-02 ระบบต้องตรวจสอบความว่างของพื้นที่ตามช่วงเวลาที่เลือกก่อนยืนยันการจอง                    <- UC-04 ขั้น 3-4
- FR-BKG-03 เมื่อพื้นที่ว่าง ระบบต้องบันทึกการจองและแจ้งผลสำเร็จ                                   <- UC-04 ขั้น 5-6
- FR-BKG-04 เมื่อพื้นที่ไม่ว่าง ระบบต้องแจ้งให้เลือกพื้นที่หรือเวลาอื่น โดยไม่สร้างรายการจองซ้อน            <- UC-04 alt 4a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-REL-03 (เสนอเพิ่ม) การตรวจสอบและบันทึกการจองต้องป้องกันการจองซ้อนเมื่อมีผู้ใช้จองพร้อมกัน (concurrency)

## Acceptance Criteria
- [ ] AC-BKG-01 (FR-BKG-01)
      Given มีพื้นที่เปิดให้บริการในระบบ
      When  นักศึกษาเลือกบริการพื้นที่
      Then  ระบบแสดงรายการพื้นที่ที่ใช้งานได้พร้อมช่วงเวลาให้เลือก
- [ ] AC-BKG-02 (FR-BKG-02, FR-BKG-03)
      Given มีพื้นที่ว่างในช่วงเวลาที่นักศึกษาเลือก
      When  นักศึกษายืนยันการจอง
      Then  ระบบตรวจสอบความว่างผ่าน บันทึกการจอง และแจ้งผลสำเร็จ
- [ ] AC-BKG-03 (FR-BKG-02, FR-BKG-04)
      Given พื้นที่ที่เลือกไม่ว่างในช่วงเวลานั้น
      When  นักศึกษาพยายามจอง
      Then  ระบบแจ้งให้เลือกพื้นที่หรือเวลาอื่น และไม่มีรายการจองซ้อนเกิดขึ้น
- [ ] AC-BKG-04 (NFR-REL-03)
      Given มีผู้ใช้สองคนพยายามจองพื้นที่และเวลาเดียวกันพร้อมกัน
      When  ทั้งสองยืนยันเกือบพร้อมกัน
      Then  ระบบอนุญาตให้จองสำเร็จเพียงรายการเดียว และอีกรายการได้รับแจ้งว่าพื้นที่ไม่ว่าง

## Assumptions & Open Questions
- ASM-01 พื้นที่แต่ละประเภท (โต๊ะเดี่ยว/ห้องกลุ่ม ฯลฯ) มีจำนวนจำกัดและกำหนดไว้ล่วงหน้าโดยห้องสมุด
- Q-01 นักศึกษาจองพื้นที่ล่วงหน้าได้กี่วัน และจองได้กี่รายการต่อวัน? -> ถามห้องสมุด (คล้าย BR-LNS-01/02 ของการยืม)
- Q-02 หากนักศึกษาไม่มาใช้พื้นที่ตามเวลาที่จอง ต้องมีการยกเลิกอัตโนมัติ (no-show) หรือไม่? -> ถามห้องสมุด
- Q-03 ต้องรองรับการยกเลิก/แก้ไขการจองหรือไม่ (ปัจจุบัน FR-BKG-01..04 ยังไม่ครอบคลุม)? -> ถามห้องสมุด
