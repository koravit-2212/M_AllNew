# Feature: จอง/ใช้พื้นที่ในห้องสมุด (Reserve/Use Library Space)
Spec ID: SPEC-LIB-004 | Source: Use Case Specification (UC-04) | Use case: UC-04
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาที่มีสิทธิ์ใช้บริการสามารถตรวจสอบและจองพื้นที่สำหรับอ่านหนังสือหรือทำงานได้แบบเรียลไทม์
โดยข้อมูลการจองต้องผูกกับตัวตนนักศึกษาที่ยืนยันแล้วเท่านั้น

## Scope
### In scope
- แสดงพื้นที่ที่สามารถใช้งานได้ และให้นักศึกษาเลือกพื้นที่/ช่วงเวลา
- ตรวจสอบพื้นที่ว่าง บันทึกการจอง และแจ้งผลการจอง
### Out of scope
- การยืนยันตัวตน/ตรวจสอบสิทธิ์การเข้าใช้บริการ -> UC-01 เข้าใช้บริการห้องสมุด, UC-02 ตรวจสอบสิทธิ์
  การเข้าใช้บริการ (ถือเป็น precondition)
- การจัดการข้อมูลพื้นที่/ผังห้องสมุด -> UC-11 จัดการข้อมูลหนังสือและบริการ

## Constraints
- DOM-SEC-02 ข้อมูลการจองต้องผูกกับตัวตนนักศึกษาที่ยืนยันแล้วเท่านั้น
- CON-DATA-01 สถานะพื้นที่ว่าง/ไม่ว่างต้องปรับปรุงแบบเรียลไทม์เพื่อป้องกันการจองซ้อน

## Requirements
- FR-SPC-01 ระบบต้องแสดงพื้นที่ที่สามารถใช้งานได้เมื่อนักศึกษาเลือกบริการพื้นที่      <- UC-04 ขั้นที่ 1-2
- FR-SPC-02 ระบบต้องตรวจสอบพื้นที่ว่างตามพื้นที่และช่วงเวลาที่นักศึกษาเลือก           <- UC-04 ขั้นที่ 3-4
- FR-SPC-03 เมื่อพื้นที่ว่าง ระบบต้องบันทึกการจองและแจ้งผลการจองสำเร็จ                <- UC-04 ขั้นที่ 5-6
- FR-SPC-04 เมื่อพื้นที่ที่เลือกไม่ว่าง ระบบต้องแจ้งให้นักศึกษาเลือกพื้นที่หรือเวลาอื่น
  โดยไม่บันทึกการจองซ้อน                                              <- UC-04 alternative (พื้นที่ไม่ว่าง)

## Quality Requirements
- NFR-PERF-04 ระบบต้องแสดงพื้นที่ว่างแบบเรียลไทม์
- NFR-SEC-02 ข้อมูลการจองต้องผูกกับตัวตนนักศึกษาที่ยืนยันแล้วเท่านั้น

## Acceptance Criteria
- [ ] AC-SPC-01 (FR-SPC-03)
      Given มีพื้นที่ว่างในช่วงเวลาที่นักศึกษาเลือก
      When  นักศึกษายืนยันการจอง
      Then  ระบบต้องบันทึกการจองและแจ้งผลสำเร็จ
- [ ] AC-SPC-02 (FR-SPC-04)
      Given พื้นที่ที่เลือกไม่ว่างในช่วงเวลานั้น
      When  นักศึกษาพยายามจอง
      Then  ระบบต้องแจ้งให้เลือกพื้นที่หรือเวลาอื่น
- [ ] AC-SPC-03 (NFR-PERF-04)
      Given มีการจองพื้นที่เกิดขึ้นในระบบ
      When  นักศึกษาคนอื่นเปิดดูสถานะพื้นที่
      Then  สถานะพื้นที่ว่าง/ไม่ว่างต้องอัปเดตแบบเรียลไทม์

## Assumptions & Open Questions
- ASM-01 นักศึกษาต้องผ่านการยืนยันตัวตนและมีสิทธิ์ใช้บริการมาก่อน (ตาม pre-condition ของ UC-04)
- Q-01 นักศึกษาสามารถจองพื้นที่ได้กี่ครั้ง/กี่ชั่วโมงต่อวัน มีข้อจำกัดหรือไม่?
- Q-02 หากนักศึกษาไม่มาใช้พื้นที่ตามเวลาที่จอง (no-show) ระบบต้องยกเลิกการจองอัตโนมัติหรือไม่?
