# Feature: ประชาสัมพันธ์บริการห้องสมุด (Announcements)
Spec ID: SPEC-PRO-001 | Source: Use Case Specification ระบบห้องสมุด, UC-12 | Use case: UC-12
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
เจ้าหน้าที่ประชาสัมพันธ์เพิ่มหัวข้อ รายละเอียด และสื่อประกอบของข่าวสาร/กิจกรรม ตรวจสอบความถูกต้อง
แล้วเผยแพร่ให้ผู้ใช้บริการเห็น เพื่อให้นักศึกษารับรู้ข้อมูลบริการและกิจกรรมของห้องสมุดอย่างครบถ้วน

## Scope
### In scope
- สร้างเนื้อหาข่าวสาร (หัวข้อ รายละเอียด รูปภาพ/เอกสารประกอบ) ตรวจสอบ และเผยแพร่
### Out of scope
- การส่งการแจ้งเตือนไปยังนักศึกษารายบุคคลเมื่อมีข่าวใหม่ (UC-08)

## Constraints
- ไม่มี Business Rule เฉพาะ

## Requirements
- FR-PRO-01 ระบบต้องให้เจ้าหน้าที่เพิ่มหัวข้อ รายละเอียดข่าวสาร และรูปภาพ/เอกสารประกอบ (ถ้ามี)  <- UC-12 ขั้น 1-4
- FR-PRO-02 ระบบต้องให้เจ้าหน้าที่ตรวจสอบข้อมูลก่อนเผยแพร่ โดยเริ่มจากการตรวจสอบรูปแบบและไฟล์แบบอัตโนมัติในชั้นแรก (เช่น ชนิดไฟล์ ขนาด และฟิลด์บังคับ) หากไม่ผ่านระบบจะปฏิเสธทันที และเมื่อผ่านแล้วต้องมีขั้นตอนการอนุมัติ (Approval Workflow) จากผู้มีอำนาจหรือผู้ดูแลระบบอีกชั้นหนึ่งก่อนเผยแพร่สู่สาธารณะจริง <- UC-12 ขั้น 5
- FR-PRO-03 เมื่อเผยแพร่ ระบบต้องแสดงข่าวสารให้ผู้ใช้บริการเห็น และต้องรองรับการตั้งเวลาเผยแพร่ล่วงหน้า (Schedule Publish) โดยกำหนดวัน-เวลาเริ่มและสิ้นสุดการเผยแพร่อัตโนมัติ พร้อมตัวเลือก "เผยแพร่ทันที (Publish Now)" สำหรับข่าวเร่งด่วน <- UC-12 ขั้น 6-7
- FR-PRO-04 เมื่อข้อมูลหรือรูปภาพไม่ผ่านการตรวจสอบอัตโนมัติ ระบบต้องไม่อนุญาตให้เผยแพร่และแจ้งเหตุผล <- UC-12 exception 5a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ

## Acceptance Criteria
- [ ] AC-PRO-01 (FR-PRO-01, FR-PRO-02, FR-PRO-03)
      Given เจ้าหน้าที่กรอกข้อมูลข่าวสารครบถ้วนและผ่านการตรวจสอบรูปแบบและไฟล์แบบอัตโนมัติเพิ่มเติมตามเงื่อนไขที่กำหนดแล้ว
      And   มีขั้นตอนการอนุมัติจากผู้มีอำนาจหรือผู้ดูแลระบบเรียบร้อยก่อนเผยแพร่
      When  เจ้าหน้าที่กดเผยแพร่ข่าวสารหรือกำหนดเวลาเผยแพร่ล่วงหน้า
      Then  ระบบแสดงข่าวสารให้ผู้ใช้บริการเห็นตามวันเวลาเริ่มการเผยแพร่ที่กำหนด หรือทันทีหากเลือกเผยแพร่ทันที
- [ ] AC-PRO-02 (FR-PRO-04)
      Given ข้อมูลข่าวสารหรือรูปภาพไม่ผ่านการตรวจสอบอัตโนมัติ
      When  เจ้าหน้าที่พยายามเผยแพร่
      Then  ระบบไม่อนุญาตให้เผยแพร่และแจ้งเหตุผล

## Assumptions & Open Questions
- ASM-01 การเผยแพร่ข่าวสารจากฟีเจอร์นี้เป็นตัวกระตุ้น (trigger) ของ UC-08 ที่ส่งการแจ้งเตือนไปยังนักศึกษา
- ASM-02 การตรวจสอบรูปแบบและไฟล์แบบอัตโนมัติเป็นชั้นแรกก่อนการอนุมัติ หากไม่ผ่านระบบจะปฏิเสธทันที
- ASM-03 หลังจากผ่านการตรวจสอบอัตโนมัติแล้ว ต้องมี Approval Workflow จากผู้มีอำนาจหรือผู้ดูแลระบบอีกชั้นหนึ่งก่อนเผยแพร่สู่สาธารณะจริง
- ASM-04 ระบบรองรับการตั้งเวลาเผยแพร่ล่วงหน้า (Schedule Publish) โดยกำหนดวัน-เวลาเริ่มและสิ้นสุดการเผยแพร่อัตโนมัติ พร้อมตัวเลือก "เผยแพร่ทันที (Publish Now)" สำหรับข่าวเร่งด่วน
