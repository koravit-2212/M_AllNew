# Feature: ประชาสัมพันธ์บริการห้องสมุด (Announcements)
Spec ID: SPEC-PRO-001 | Source: Use Case Specification ระบบห้องสมุด, UC-12 | Use case: UC-12
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
เจ้าหน้าที่ประชาสัมพันธ์เพิ่มหัวข้อ รายละเอียด และสื่อประกอบของข่าวสาร/กิจกรรม ตรวจสอบความถูกต้อง
แล้วเผยแพร่ให้ผู้ใช้บริการเห็น เพื่อให้นักศึกษารับรู้ข้อมูลบริการและกิจกรรมของห้องสมุดอย่างครบถ้วน

## Scope
### In scope
- สร้างเนื้อหาข่าวสาร (หัวข้อ รายละเอียด รูปภาพ/เอกสารประกอบ) ตรวจสอบ และเผยแพร่
### Out of scope
- การส่งการแจ้งเตือนไปยังนักศึกษารายบุคคลเมื่อมีข่าวใหม่ (UC-08)

## Constraints
- ไม่มี Business Rule เฉพาะ

## Requirements
- FR-PRO-01 ระบบต้องให้เจ้าหน้าที่เพิ่มหัวข้อ รายละเอียดข่าวสาร และรูปภาพ/เอกสารประกอบ (ถ้ามี)  <- UC-12 ขั้น 1-4
- FR-PRO-02 ระบบต้องให้เจ้าหน้าที่ตรวจสอบข้อมูลก่อนเผยแพร่                                    <- UC-12 ขั้น 5
- FR-PRO-03 เมื่อเผยแพร่ ระบบต้องแสดงข่าวสารให้ผู้ใช้บริการเห็น                                <- UC-12 ขั้น 6-7
- FR-PRO-04 เมื่อข้อมูลหรือรูปภาพไม่ผ่านการตรวจสอบ ระบบต้องไม่อนุญาตให้เผยแพร่และแจ้งเหตุผล      <- UC-12 exception 5a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ

## Acceptance Criteria
- [ ] AC-PRO-01 (FR-PRO-01, FR-PRO-02, FR-PRO-03)
      Given เจ้าหน้าที่กรอกข้อมูลข่าวสารครบถ้วนและตรวจสอบแล้ว
      When  เจ้าหน้าที่กดเผยแพร่ข่าวสาร
      Then  ระบบแสดงข่าวสารให้ผู้ใช้บริการเห็น
- [ ] AC-PRO-02 (FR-PRO-04)
      Given ข้อมูลข่าวสารไม่ผ่านการตรวจสอบ
      When  เจ้าหน้าที่พยายามเผยแพร่
      Then  ระบบไม่อนุญาตให้เผยแพร่และแจ้งเหตุผล

## Assumptions & Open Questions
- ASM-01 การเผยแพร่ข่าวสารจากฟีเจอร์นี้เป็นตัวกระตุ้น (trigger) ของ UC-08 ที่ส่งการแจ้งเตือนไปยังนักศึกษา
- Q-01 "ตรวจสอบข้อมูล" (ขั้น 5 / exception 5a) เป็นการตรวจสอบอัตโนมัติ (เช่น ขนาดไฟล์ รูปแบบ) หรือมีการอนุมัติโดยผู้บังคับบัญชาอีกชั้น? -> ถามเจ้าหน้าที่ประชาสัมพันธ์
- Q-02 รองรับการตั้งเวลาเผยแพร่ล่วงหน้า (schedule publish) หรือไม่? -> ถามห้องสมุด
