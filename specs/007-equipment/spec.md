# Feature: ใช้บริการยืมอุปกรณ์ (Equipment Loan)
Spec ID: SPEC-EQP-001 | Source: Use Case Specification ระบบห้องสมุด, UC-07 | Use case: UC-07
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
นักศึกษาเลือกอุปกรณ์อำนวยความสะดวก (ปลั๊กไฟ ร่ม ถุงผ้า) และเจ้าหน้าที่อนุมัติการยืมหลังตรวจสอบข้อมูล
เพื่อให้ห้องสมุดควบคุมจำนวนอุปกรณ์และป้องกันการค้างคืนได้

## Scope
### In scope
- เลือกอุปกรณ์ ตรวจสอบจำนวนคงเหลือ และตรวจสอบข้อมูลนักศึกษา (รวมถึงรายการค้างคืน) ก่อนอนุมัติ
- บันทึกการยืมและลดจำนวนอุปกรณ์คงเหลือ
### Out of scope
- การยืม-คืนหนังสือ (UC-05, แม้ใช้กฎการคืนตรงเวลาร่วมกัน BR-LNS-02)
- การจัดการจำนวน/ประเภทอุปกรณ์ในระบบ (UC-11 หรือ UC-13)

## Constraints
- CON-LNS-02 ผู้ใช้บริการต้องคืนหนังสือและอุปกรณ์ภายในระยะเวลาที่ห้องสมุดกำหนด (BR-LNS-02)

## Requirements
- FR-EQP-01 ระบบต้องให้นักศึกษาเลือกอุปกรณ์ที่ต้องการยืม (ปลั๊กไฟ ร่ม ถุงผ้า)                     <- UC-07 ขั้น 1
- FR-EQP-02 ระบบต้องตรวจสอบจำนวนอุปกรณ์คงเหลือก่อนดำเนินการต่อ                             <- UC-07 ขั้น 2
- FR-EQP-03 ระบบต้องให้เจ้าหน้าที่ตรวจสอบข้อมูลนักศึกษา รวมถึงรายการค้างคืน ก่อนอนุมัติการยืม     <- UC-07 ขั้น 3
- FR-EQP-04 เมื่อเจ้าหน้าที่อนุมัติ ระบบต้องบันทึกการยืม (รวมการกำหนด due date ตามประเภทอุปกรณ์) และลดจำนวนอุปกรณ์คงเหลือ                  <- UC-07 ขั้น 4-5
- FR-EQP-05 เมื่ออุปกรณ์หมด ระบบต้องแจ้งว่าไม่สามารถยืมได้                                    <- UC-07 exception 2a
- FR-EQP-06 เมื่อนักศึกษามีรายการค้างคืน เจ้าหน้าที่ต้องตรวจสอบก่อนอนุมัติการยืมใหม่               <- UC-07 exception 3a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ

## Acceptance Criteria
- [ ] AC-EQP-01 (FR-EQP-01)
      Given มีรายการอุปกรณ์ให้บริการในระบบ
      When  นักศึกษาเข้าหน้าจอยืมอุปกรณ์
      Then  ระบบแสดงประเภทอุปกรณ์ที่สามารถยืมได้ให้เลือก
- [ ] AC-EQP-02 (FR-EQP-02, FR-EQP-03, FR-EQP-04)
      Given อุปกรณ์ที่ต้องการมีจำนวนเพียงพอและนักศึกษาไม่มีรายการค้างคืน
      When  เจ้าหน้าที่อนุมัติการยืม
      Then  ระบบบันทึกการยืมและลดจำนวนอุปกรณ์คงเหลือ
- [ ] AC-EQP-03 (FR-EQP-02, FR-EQP-05)
      Given อุปกรณ์ที่ต้องการหมด
      When  นักศึกษาขอยืมอุปกรณ์
      Then  ระบบแจ้งว่าไม่สามารถยืมได้
- [ ] AC-EQP-04 (FR-EQP-03, FR-EQP-06)
      Given นักศึกษามีรายการค้างคืนอุปกรณ์หรือหนังสือ
      When  นักศึกษาขอยืมอุปกรณ์เพิ่ม
      Then  เจ้าหน้าที่ต้องตรวจสอบรายการค้างคืนก่อนตัดสินใจอนุมัติ

## Assumptions & Open Questions
- ASM-01 การอนุมัติการยืมอุปกรณ์ต้องผ่านเจ้าหน้าที่เสมอ ไม่ใช่กระบวนการอัตโนมัติทั้งหมด
- ASM-02 หากนักศึกษามีรายการค้างคืน ระบบจะปฏิเสธการยืมอัตโนมัติและบล็อกการทำรายการผ่านระบบจนกว่าจะคืนทรัพยากรและชำระค่าปรับเรียบร้อย อย่างไรก็ตาม ระบบต้องมีฟังก์ชันให้เจ้าหน้าที่ปลดล็อก (override) เพื่ออนุญาตเป็นกรณีพิเศษตามดุลยพินิจของเจ้าหน้าที่
- ASM-03 ระยะเวลายืมสำหรับอุปกรณ์อำนวยความสะดวก (ปลั๊กไฟ / ร่ม / ถุงผ้า) ให้ยืมได้ 1–2 วัน (หรือคืนภายในเวลาปิดทำการของวันที่ยืม) โดยกำหนด due date ตามประเภทอุปกรณ์และนโยบายห้องสมุด
