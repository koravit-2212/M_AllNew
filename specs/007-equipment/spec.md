# Feature: ยืมอุปกรณ์อำนวยความสะดวก (Borrow Convenience Equipment)
Spec ID: SPEC-LIB-007 | Source: Use Case Specification (UC-07) | Use case: UC-07
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาสามารถยืมอุปกรณ์อำนวยความสะดวก (ปลั๊กไฟ ร่ม ถุงผ้า) จากเจ้าหน้าที่ห้องสมุดได้
โดยระบบตรวจสอบจำนวนอุปกรณ์คงเหลือแบบเรียลไทม์และป้องกันการยืมซ้ำเมื่อมีรายการค้างคืน

## Scope
### In scope
- ตรวจสอบจำนวนอุปกรณ์คงเหลือ และให้เจ้าหน้าที่ตรวจสอบข้อมูลนักศึกษาก่อนอนุมัติ
- บันทึกการยืมอุปกรณ์และปรับปรุงจำนวนคงเหลือ
### Out of scope
- การคืนอุปกรณ์ -> ไม่ได้ระบุรายละเอียดไว้ในเอกสารต้นทาง (ต้องยืนยันเพิ่ม)
- การจัดการ/เพิ่มจำนวนอุปกรณ์เข้าคลัง -> UC-11 จัดการข้อมูลหนังสือและบริการ
- การยืนยันตัวตน/ตรวจสอบสิทธิ์เข้าใช้บริการห้องสมุด -> UC-01, UC-02 (ถือเป็น precondition)

## Constraints
- ROLE-STAFF-01 การอนุมัติการยืมต้องผ่านการตรวจสอบโดยเจ้าหน้าที่ห้องสมุด
- CON-DATA-02 จำนวนอุปกรณ์คงเหลือต้องปรับปรุงแบบทันที (real-time) เพื่อป้องกันข้อมูลไม่ตรงกัน

## Requirements
- FR-EQP-01 ระบบต้องตรวจสอบจำนวนอุปกรณ์คงเหลือเมื่อนักศึกษาเลือกอุปกรณ์ที่ต้องการ         <- UC-07 ขั้นที่ 1-2
- FR-EQP-02 เจ้าหน้าที่ต้องตรวจสอบข้อมูลนักศึกษาก่อนอนุมัติการยืม                        <- UC-07 ขั้นที่ 3
- FR-EQP-03 เมื่ออนุมัติแล้ว ระบบต้องบันทึกการยืมและลดจำนวนอุปกรณ์คงเหลือ                 <- UC-07 ขั้นที่ 4-5
- FR-EQP-04 เมื่ออุปกรณ์หมด ระบบต้องแจ้งว่าไม่สามารถยืมได้                             <- UC-07 exception 2a
- FR-EQP-05 เมื่อนักศึกษามีรายการค้างคืน เจ้าหน้าที่ต้องตรวจสอบก่อนอนุมัติการยืมครั้งใหม่    <- UC-07 exception 3a

## Quality Requirements
- NFR-DATA-02 ระบบต้องปรับปรุงจำนวนอุปกรณ์คงเหลือแบบทันที (real-time)
- NFR-USAB-02 ขั้นตอนการยืมอุปกรณ์ต้องทำได้ภายในไม่เกิน 3 ขั้นตอนหลัก

## Acceptance Criteria
- [ ] AC-EQP-01 (FR-EQP-03, NFR-DATA-02)
      Given อุปกรณ์ที่ต้องการมีจำนวนเพียงพอและนักศึกษาไม่มีรายการค้างคืน
      When  เจ้าหน้าที่อนุมัติการยืม
      Then  ระบบต้องบันทึกการยืมและลดจำนวนอุปกรณ์คงเหลือ
- [ ] AC-EQP-02 (FR-EQP-04)
      Given อุปกรณ์ที่ต้องการหมด
      When  นักศึกษาขอยืมอุปกรณ์
      Then  ระบบต้องแจ้งว่าไม่สามารถยืมได้
- [ ] AC-EQP-03 (FR-EQP-05)
      Given นักศึกษามีรายการค้างคืนอุปกรณ์อยู่
      When  นักศึกษาขอยืมอุปกรณ์เพิ่ม
      Then  เจ้าหน้าที่ต้องตรวจสอบรายการค้างคืนก่อนอนุมัติ

## Assumptions & Open Questions
- ASM-01 การยืมอุปกรณ์ต้องผ่านการอนุมัติของเจ้าหน้าที่เสมอ (ไม่มีเครื่องอัตโนมัติเหมือน UC-05)
- Q-01 อุปกรณ์แต่ละประเภทมีระยะเวลายืมสูงสุดเท่าใด และมีบทลงโทษหากไม่คืนหรือไม่?
