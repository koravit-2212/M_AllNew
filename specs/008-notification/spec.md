# Feature: รับข่าวสารและการแจ้งเตือน (News & Notification)
Spec ID: SPEC-LIB-008 | Source: Use Case Specification (UC-08) | Use case: UC-08
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
เมื่อเจ้าหน้าที่เพิ่มข่าวสารหรือประกาศใหม่ ระบบต้องส่งการแจ้งเตือนถึงนักศึกษาได้อย่างรวดเร็ว
และเชื่อถือได้ พร้อมเก็บประวัติการแจ้งเตือนไว้ตรวจสอบย้อนหลัง

## Scope
### In scope
- บันทึกข่าวสาร/ประกาศที่เจ้าหน้าที่เพิ่มเข้าระบบ และส่งต่อไปยังระบบแจ้งเตือน
- แจ้งเตือนนักศึกษา และให้นักศึกษาเปิดดูรายละเอียดข่าวสาร
### Out of scope
- การสร้าง/เผยแพร่เนื้อหาประชาสัมพันธ์แบบเต็มรูปแบบ (รูปภาพ, เอกสารประกอบ) -> UC-12
  ประชาสัมพันธ์บริการห้องสมุด
- การจัดการสิทธิ์ผู้รับข่าวสาร -> UC-10 จัดการข้อมูลผู้ใช้บริการ

## Constraints
- IF-NOTI-01 ระบบต้องเชื่อมต่อกับระบบแจ้งเตือน (SMS/LINE/Push) แบบ asynchronous

## Requirements
- FR-NEWS-01 ระบบต้องบันทึกข่าวสารหรือประกาศเมื่อเจ้าหน้าที่เพิ่มเข้าระบบ                <- UC-08 ขั้นที่ 1-2
- FR-NEWS-02 ระบบต้องส่งข้อมูลไปยังระบบแจ้งเตือน และแจ้งเตือนนักศึกษาที่เกี่ยวข้อง          <- UC-08 ขั้นที่ 3-4
- FR-NEWS-03 นักศึกษาต้องสามารถเปิดดูรายละเอียดข่าวสารที่ได้รับแจ้งเตือนได้                <- UC-08 ขั้นที่ 5
- FR-NEWS-04 เมื่อส่งการแจ้งเตือนไม่สำเร็จ ระบบต้องบันทึกไว้และส่งซ้ำในภายหลัง             <- UC-08 exception 4a

## Quality Requirements
- NFR-PERF-07 ระบบต้องส่งการแจ้งเตือนถึงนักศึกษาภายใน 1 นาทีหลังเผยแพร่
- NFR-REL-02 ระบบต้องบันทึกประวัติการแจ้งเตือนเพื่อตรวจสอบย้อนหลังได้

## Acceptance Criteria
- [ ] AC-NEWS-01 (FR-NEWS-02, NFR-PERF-07)
      Given เจ้าหน้าที่เพิ่มข่าวสารใหม่ในระบบ
      When  ระบบประมวลผลข้อมูล
      Then  ระบบต้องส่งการแจ้งเตือนไปยังนักศึกษาที่เกี่ยวข้องภายใน 1 นาที
- [ ] AC-NEWS-02 (FR-NEWS-03)
      Given นักศึกษาได้รับการแจ้งเตือน
      When  นักศึกษาเปิดดูข่าวสาร
      Then  ระบบต้องแสดงรายละเอียดข่าวสารครบถ้วน
- [ ] AC-NEWS-03 (FR-NEWS-04, NFR-REL-02)
      Given ระบบส่งการแจ้งเตือนไม่สำเร็จ
      When  ครบกำหนดรอบส่ง
      Then  ระบบต้องบันทึกรายการไว้และนำเข้าคิวส่งซ้ำในภายหลัง

## Assumptions & Open Questions
- ASM-01 การแจ้งเตือนไม่บล็อกขั้นตอนการเพิ่มข่าวสารของเจ้าหน้าที่ (ทำงานแบบ asynchronous)
- Q-01 "นักศึกษาที่เกี่ยวข้อง" หมายถึงนักศึกษาทุกคน หรือกลุ่มเป้าหมายเฉพาะ (เช่น ตามคณะ/ชั้นปี)?
