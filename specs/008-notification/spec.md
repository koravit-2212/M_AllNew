# Feature: รับข่าวสารและการแจ้งเตือน (Notifications)
Spec ID: SPEC-NTF-001 | Source: Use Case Specification ระบบห้องสมุด, UC-08 | Use case: UC-08
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
เมื่อเจ้าหน้าที่เพิ่มข่าวสาร/ประกาศใหม่ ระบบต้องส่งข้อมูลไปยังระบบแจ้งเตือนและแจ้งนักศึกษาที่เกี่ยวข้อง
ให้เปิดดูข่าวสารได้ครบถ้วน เพื่อให้ห้องสมุดสื่อสารข่าวสารถึงนักศึกษาได้อย่างทั่วถึงและทันท่วงที

## Scope
### In scope
- บันทึกข่าวสาร/ประกาศที่เจ้าหน้าที่เพิ่ม และส่งต่อไปยังระบบแจ้งเตือน
- แจ้งเตือนนักศึกษา และแสดงรายละเอียดข่าวสารเมื่อเปิดดู รวมถึงส่งซ้ำเมื่อแจ้งเตือนไม่สำเร็จ
### Out of scope
- การสร้าง/แก้ไขเนื้อหาประชาสัมพันธ์แบบเต็มรูปแบบ (รูปภาพ/เอกสารประกอบ) ซึ่งอยู่ใน UC-12

## Constraints
- ไม่มี Business Rule เฉพาะ (อ้างอิง NFR ด้านความต่อเนื่องของบริการ)

 - FR-NTF-01 ระบบต้องบันทึกข่าวสาร/ประกาศที่เจ้าหน้าที่เพิ่ม และส่งข้อมูลไปยังระบบแจ้งเตือน ผ่านช่องทาง LINE Official Account, Email (อีเมลสถาบัน) และ In-App / Web-App Notification       <- UC-08 ขั้น 1-3
 - FR-NTF-02 ระบบต้องแจ้งเตือนนักศึกษาที่เกี่ยวข้องเมื่อมีข่าวสารใหม่                              <- UC-08 ขั้น 4
 - FR-NTF-03 ระบบต้องแสดงรายละเอียดข่าวสารครบถ้วนเมื่อนักศึกษาเปิดดู                            <- UC-08 ขั้น 5
 - FR-NTF-04 เมื่อส่งการแจ้งเตือนไม่สำเร็จ ระบบต้องบันทึกไว้และส่งซ้ำในภายหลัง (พยายามส่งซ้ำสูงสุด 3 ครั้ง ด้วยนโยบาย exponential backoff เริ่มต้นที่ 5 นาที; หากยังไม่สำเร็จ ให้บันทึกสถานะเป็น failed, เก็บ Error Log และพยายามส่งผ่านช่องทางสำรอง)                     <- UC-08 exception 4a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ
- NFR-REL-02 ระบบต้องสามารถให้บริการได้อย่างต่อเนื่องในช่วงเวลาที่ห้องสมุดเปิดให้บริการ

## Acceptance Criteria
 - [ ] AC-NTF-01 (FR-NTF-01, FR-NTF-02)
       Given เจ้าหน้าที่เพิ่มข่าวสารใหม่ในระบบ
       When  ระบบประมวลผลข้อมูล
       Then  ระบบส่งการแจ้งเตือนไปยังนักศึกษาที่เกี่ยวข้อง ผ่านช่องทางที่รองรับ (LINE, Email, In-App)
- [ ] AC-NTF-02 (FR-NTF-03)
      Given นักศึกษาได้รับการแจ้งเตือน
      When  นักศึกษาเปิดดูข่าวสาร
      Then  ระบบแสดงรายละเอียดข่าวสารครบถ้วน
- [ ] AC-NTF-03 (FR-NTF-04)
      Given การส่งการแจ้งเตือนครั้งแรกไม่สำเร็จ
      When  ระบบตรวจพบความล้มเหลว
      Then  ระบบบันทึกรายการไว้และส่งซ้ำในภายหลังโดยอัตโนมัติ

## Assumptions & Open Questions
 - ASM-01 "นักศึกษาที่เกี่ยวข้อง" หมายถึงนักศึกษาทุกคนที่มีบัญชีในระบบ เว้นแต่มีการระบุกลุ่มเป้าหมายเฉพาะ
 - ASM-02 ระบบรองรับช่องทางแจ้งเตือนหลัก 3 ช่องทาง: LINE Official Account, Email (อีเมลสถาบัน) และ In-App / Web-App Notification
 - ASM-03 เมื่อนำส่งแจ้งเตือนไม่สำเร็จ ระบบจะพยายามส่งซ้ำสูงสุด 3 ครั้ง ด้วย exponential backoff เริ่มต้นที่ 5 นาที; หากยังไม่สำเร็จ ให้บันทึกเป็น failed, เก็บ Error Log และพยายามส่งผ่านช่องทางสำรอง (fallback)
 - ASM-04 การระบุกลุ่มเป้าหมาย: ให้ใช้ UI Dynamic Filters บนหน้าเว็บเป็นหลักสำหรับเลือกคณะและชั้นปี; รองรับ Saved Segments สำหรับบันทึกกลุ่มที่ใช้บ่อย; รองรับ CSV Upload สำหรับอัปโหลดรายชื่อเฉพาะกิจ. (ตอบโดยเจ้าหน้าที่)
