# Feature: ใช้บริการปริ้นเอกสาร (Printing)
Spec ID: SPEC-PRT-001 | Source: Use Case Specification ระบบห้องสมุด, UC-06 | Use case: UC-06
Owner: TBD | Status: Draft v1 | Updated: 2569-09-19

## Goal
นักศึกษาเลือกไฟล์ กำหนดจำนวนหน้า/ชุด เห็นค่าใช้จ่ายล่วงหน้า และยืนยันพิมพ์ เพื่อให้ได้รับเอกสาร
ที่ถูกต้องตามที่กำหนด และห้องสมุดบริหารจัดการทรัพยากรเครื่องพิมพ์ได้อย่างมีประสิทธิภาพ

## Scope
### In scope
- เลือกไฟล์ กำหนดตัวเลือกการพิมพ์ (จำนวนหน้า/จำนวนชุด) และคำนวณค่าใช้บริการ
- ส่งงานพิมพ์ไปยังเครื่องปริ้น และบันทึกข้อมูลการใช้บริการปริ้น
### Out of scope
- การชำระเงินค่าปริ้น (หากมีระบบชำระเงินแยก - ดู Open Question)
- การจัดการ/บำรุงรักษาเครื่องปริ้นโดยเจ้าหน้าที่

## Constraints
- IF-PRN-01 ระบบต้องส่งงานพิมพ์ไปยังเครื่องปริ้นผ่านระบบคิวพิมพ์ (print spooler) ที่ฝ่าย IT กำหนด
- CON-FILE-01 ระบบต้องรองรับเฉพาะรูปแบบไฟล์ที่กำหนดไว้ (ดู Open Question Q-01)

## Requirements
- FR-PRT-01 ระบบต้องให้นักศึกษาเลือกไฟล์และแสดงตัวเลือกการพิมพ์                          <- UC-06 ขั้น 1-2
- FR-PRT-02 ระบบต้องคำนวณค่าใช้บริการตามจำนวนหน้าและจำนวนชุดที่กำหนด                     <- UC-06 ขั้น 3-4
- FR-PRT-03 เมื่อยืนยันการพิมพ์ ระบบต้องส่งงานไปยังเครื่องปริ้นและบันทึกข้อมูลการใช้บริการ    <- UC-06 ขั้น 5-6
- FR-PRT-04 เมื่อไฟล์ไม่รองรับ ระบบต้องแจ้งเตือนและไม่ดำเนินการต่อ                          <- UC-06 exception 1a
- FR-PRT-05 เมื่อเครื่องปริ้นไม่พร้อมใช้งาน ระบบต้องแจ้งเตือนผู้ใช้และไม่ส่งงานพิมพ์             <- UC-06 exception 6a

## Quality Requirements
- NFR-USB-01 ระบบต้องสามารถใช้งานผ่าน Web Browser บนคอมพิวเตอร์และโทรศัพท์มือถือ

## Acceptance Criteria
- [ ] AC-PRT-01 (FR-PRT-01, FR-PRT-02)
      Given นักศึกษาเลือกไฟล์ที่รองรับ
      When  นักศึกษากำหนดจำนวนหน้าและจำนวนชุด
      Then  ระบบแสดงตัวเลือกการพิมพ์และค่าใช้บริการที่คำนวณถูกต้องก่อนให้ยืนยัน
- [ ] AC-PRT-02 (FR-PRT-03)
      Given เครื่องปริ้นพร้อมใช้งานและไฟล์รองรับ
      When  นักศึกษายืนยันการพิมพ์
      Then  ระบบส่งงานไปยังเครื่องปริ้นและนักศึกษาได้รับเอกสารตามจำนวนที่กำหนด
- [ ] AC-PRT-03 (FR-PRT-05)
      Given เครื่องปริ้นไม่พร้อมใช้งาน
      When  นักศึกษายืนยันการพิมพ์
      Then  ระบบแจ้งเตือนผู้ใช้และไม่ส่งงานพิมพ์
- [ ] AC-PRT-04 (FR-PRT-04)
      Given ไฟล์ที่เลือกไม่รองรับ
      When  นักศึกษาเลือกไฟล์
      Then  ระบบแจ้งเตือนและไม่ให้ดำเนินการพิมพ์ต่อ

## Assumptions & Open Questions
- ASM-01 ค่าใช้บริการปริ้นคำนวณตามอัตราต่อหน้าที่ห้องสมุดกำหนดไว้ล่วงหน้า
- Q-01 ระบบต้องรองรับไฟล์ประเภทใดบ้าง (PDF/DOCX/รูปภาพ) และขนาดไฟล์สูงสุดเท่าใด? -> ถามฝ่าย IT/ห้องสมุด
- Q-02 การชำระค่าปริ้นทำอย่างไร (หักจากยอดเติมเงิน/ชำระที่เครื่อง/ผูกกับ UC-การชำระเงิน)? -> ถามห้องสมุด
