# Feature: ใช้บริการปริ้นเอกสาร (Document Printing Service)
Spec ID: SPEC-LIB-006 | Source: Use Case Specification (UC-06) | Use case: UC-06
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาสามารถพิมพ์เอกสารภายในห้องสมุดได้อย่างสะดวก โดยระบบคำนวณค่าใช้บริการและส่งงาน
ไปยังเครื่องปริ้นให้ถูกต้องตามจำนวนที่กำหนด

## Scope
### In scope
- เลือกไฟล์ที่ต้องการพิมพ์ กำหนดจำนวนหน้า/จำนวนชุด และคำนวณค่าใช้บริการ
- ส่งงานพิมพ์ไปยังเครื่องปริ้น และรับเอกสารที่พิมพ์แล้ว
### Out of scope
- การชำระเงินค่าบริการ (นอกเหนือจากการคำนวณราคา) -> ไม่มี UC ระบุไว้ในเอกสารต้นทาง (ต้องยืนยันเพิ่ม)
- การยืนยันตัวตน/ตรวจสอบสิทธิ์เข้าใช้บริการห้องสมุด -> UC-01, UC-02 (ถือเป็น precondition)

## Constraints
- CON-DEVICE-02 ต้องเชื่อมต่อกับเครื่องปริ้นที่ติดตั้งในห้องสมุด
- DOM-SEC-03 ระบบต้องรองรับไฟล์เอกสารตามรูปแบบที่กำหนดเท่านั้นเพื่อความปลอดภัย

## Requirements
- FR-PRT-01 ระบบต้องแสดงตัวเลือกการพิมพ์เมื่อนักศึกษาเลือกไฟล์ที่ต้องการพิมพ์               <- UC-06 ขั้นที่ 1-2
- FR-PRT-02 ระบบต้องคำนวณค่าใช้บริการตามจำนวนหน้าและจำนวนชุดที่กำหนด                     <- UC-06 ขั้นที่ 3-4
- FR-PRT-03 เมื่อนักศึกษายืนยันการพิมพ์ ระบบต้องส่งงานไปยังเครื่องปริ้น                    <- UC-06 ขั้นที่ 5-7
- FR-PRT-04 เมื่อไฟล์ไม่รองรับ ระบบต้องแจ้งเตือนและไม่ดำเนินการต่อ                        <- UC-06 exception 1a
- FR-PRT-05 เมื่อเครื่องปริ้นไม่พร้อมใช้งาน ระบบต้องแจ้งเตือนผู้ใช้และไม่ส่งงานพิมพ์          <- UC-06 exception 6a

## Quality Requirements
- NFR-PERF-06 ระบบต้องคำนวณค่าใช้บริการและแสดงผลภายใน 2 วินาที
- NFR-SEC-03 ระบบต้องรองรับไฟล์เอกสารตามรูปแบบที่กำหนดเท่านั้นเพื่อความปลอดภัย

## Acceptance Criteria
- [ ] AC-PRT-01 (FR-PRT-03, NFR-PERF-06)
      Given เครื่องปริ้นพร้อมใช้งานและไฟล์รองรับ
      When  นักศึกษายืนยันการพิมพ์
      Then  ระบบต้องส่งงานไปยังเครื่องปริ้นและนักศึกษาได้รับเอกสารตามจำนวนที่กำหนด
- [ ] AC-PRT-02 (FR-PRT-05)
      Given เครื่องปริ้นไม่พร้อมใช้งาน
      When  นักศึกษายืนยันการพิมพ์
      Then  ระบบต้องแจ้งเตือนผู้ใช้และไม่ส่งงานพิมพ์
- [ ] AC-PRT-03 (FR-PRT-04)
      Given ไฟล์ที่นักศึกษาเลือกไม่รองรับรูปแบบที่กำหนด
      When  นักศึกษาเลือกไฟล์
      Then  ระบบต้องแจ้งเตือนและไม่ดำเนินการต่อ

## Assumptions & Open Questions
- ASM-01 อัตราค่าบริการต่อหน้า/ต่อชุดถูกกำหนดไว้ล่วงหน้าในระบบ
- Q-01 การชำระค่าบริการพิมพ์ทำผ่านช่องทางใด (หักเครดิต, เงินสด, QR payment) และเชื่อมกับ UC ใด?
