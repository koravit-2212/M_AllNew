# Feature: จัดการข้อมูลระบบ (Manage System Data)
Spec ID: SPEC-LIB-013 | Source: Use Case Specification (UC-13) | Use case: UC-13
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-09

## Goal
เจ้าหน้าที่ห้องสมุดที่มีสิทธิ์สามารถเพิ่ม แก้ไข ลบ และค้นหาข้อมูลหนังสือ ข้อมูลบริการ
และข้อมูลการใช้บริการ เพื่อให้ข้อมูลในระบบมีความถูกต้องและเป็นปัจจุบัน โดยทุกการเปลี่ยนแปลง
ต้องถูกบันทึกเป็นประวัติ

## Scope
### In scope
- ตรวจสอบสิทธิ์เจ้าหน้าที่ และแสดงเมนู "จัดการข้อมูลระบบ" พร้อมประเภทข้อมูลที่จัดการได้
  (ข้อมูลหนังสือ, ข้อมูลบริการ, ข้อมูลการใช้บริการ)
- เพิ่ม/แก้ไข/ลบ/ค้นหาข้อมูล พร้อมตรวจสอบความถูกต้องก่อนบันทึก และบันทึก log ทุกครั้ง
### Out of scope
- การจัดการข้อมูลหนังสือ/บริการโดยเฉพาะในรายละเอียด (ฟอร์ม/ฟิลด์เฉพาะ) -> UC-11 จัดการข้อมูล
  หนังสือและบริการ
- การจัดการข้อมูลผู้ใช้บริการ (นักศึกษา) -> UC-10 จัดการข้อมูลผู้ใช้บริการ

## Constraints
- ROLE-STAFF-04 เฉพาะเจ้าหน้าที่ที่มีสิทธิ์เท่านั้นที่สามารถจัดการข้อมูลระบบได้
- DOM-AUDIT-01 ทุกการเพิ่ม แก้ไข ลบข้อมูลต้องถูกบันทึกเป็นประวัติ (log)

## Requirements
- FR-SYS-01 ระบบต้องตรวจสอบสิทธิ์ของเจ้าหน้าที่ก่อนอนุญาตให้เข้าถึงเมนู "จัดการข้อมูลระบบ"     <- UC-13 ขั้นที่ 1-2
- FR-SYS-02 ระบบต้องแสดงประเภทข้อมูลที่จัดการได้ (ข้อมูลหนังสือ, ข้อมูลบริการ, ข้อมูลการใช้บริการ)
  เมื่อเจ้าหน้าที่เลือกเมนู                                            <- UC-13 ขั้นที่ 3-4
- FR-SYS-03 ระบบต้องให้เจ้าหน้าที่เพิ่ม/แก้ไข/ลบ/ค้นหาข้อมูลตามประเภทที่เลือก                <- UC-13 ขั้นที่ 5-7
- FR-SYS-04 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึก และแสดงข้อความ "ดำเนินการสำเร็จ"
  เมื่อบันทึกสำเร็จ                                                    <- UC-13 ขั้นที่ 8-11
- FR-SYS-05 เมื่อเจ้าหน้าที่ไม่มีสิทธิ์เข้าใช้เมนูจัดการข้อมูลระบบ ระบบต้องปฏิเสธการเข้าถึงและแจ้งเตือน
  <- UC-13 exception 2a
- FR-SYS-06 เมื่อข้อมูลไม่ผ่านการตรวจสอบความถูกต้อง ระบบต้องแจ้งข้อผิดพลาดและไม่บันทึกข้อมูล    <- UC-13 exception 9a

## Quality Requirements
- NFR-SEC-05 เฉพาะเจ้าหน้าที่ที่มีสิทธิ์เท่านั้นที่สามารถจัดการข้อมูลระบบได้
- NFR-AUDIT-02 ทุกการเพิ่ม แก้ไข ลบข้อมูลต้องถูกบันทึกเป็นประวัติ (log)

## Acceptance Criteria
- [ ] AC-SYS-01 (FR-SYS-04, NFR-AUDIT-02)
      Given เจ้าหน้าที่มีสิทธิ์จัดการข้อมูลระบบและข้อมูลที่กรอกถูกต้อง
      When  เจ้าหน้าที่กดยืนยันการดำเนินการ
      Then  ระบบต้องบันทึกข้อมูลลงฐานข้อมูลและแสดงข้อความ "ดำเนินการสำเร็จ"
- [ ] AC-SYS-02 (FR-SYS-06)
      Given ข้อมูลที่เจ้าหน้าที่กรอกไม่ถูกต้อง
      When  เจ้าหน้าที่กดยืนยันการดำเนินการ
      Then  ระบบต้องแจ้งข้อผิดพลาดและไม่บันทึกข้อมูล
- [ ] AC-SYS-03 (FR-SYS-05)
      Given เจ้าหน้าที่ไม่มีสิทธิ์เข้าใช้เมนูจัดการข้อมูลระบบ
      When  เจ้าหน้าที่พยายามเข้าถึงเมนูนี้
      Then  ระบบต้องปฏิเสธการเข้าถึงและแจ้งเตือน

## Assumptions & Open Questions
- ASM-01 UC-13 เป็นเมนู/ฟังก์ชันระดับสูง (super menu) ที่ครอบคลุมการจัดการข้อมูลหลายประเภท
  ซึ่งอาจมีความซ้ำซ้อนกับ UC-11 (จัดการข้อมูลหนังสือ/บริการ) และ UC-10 (จัดการข้อมูลผู้ใช้บริการ)
  ในขอบเขตของ "ข้อมูลหนังสือ" และ "ข้อมูลบริการ" -> ควรยืนยันกับผู้เกี่ยวข้องว่า UC-13 เป็น
  entry point รวม หรือเป็นฟีเจอร์คนละส่วนกัน
- Q-01 "ข้อมูลการใช้บริการ" ใน UC-13 หมายถึงข้อมูลใด (ประวัติการเข้าใช้ห้องสมุด, ประวัติการยืม-คืน,
  หรือทั้งหมด) และเชื่อมโยงกับ UC-01/UC-05 อย่างไร?
